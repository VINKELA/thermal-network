 2. Editable design and cost assumptions

Installed CAD / route m = reference cost × [(1 − α) + α × (cost diameter / reference diameter)n]

Banded costs: cost diameter = band width × ceiling(actual diameter / band width). Each band includes its upper boundary. For example, 100 mm bands cover (0, 100], (100, 200], and so on. All diameters in a band have the same complete installed rate. Actual diameters still determine flow, pressure and pumping. The reference diameter is not rounded.

Continuous cost scaling is active. Set a positive diameter cost band width below to give all diameters within a band the same installed rate.
